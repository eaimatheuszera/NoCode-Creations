# NoCode Creations

Site institucional estático da NoCode Creations.

## Publicação na Hostinger

O arquivo principal do site é `index.html`, com as versões da logo em SVG na raiz. Para publicar manualmente, envie esses arquivos para a pasta `public_html` do domínio na Hostinger.

Para deploy conectado ao GitHub, crie um repositório para este projeto e configure a integração de Git disponível no painel da Hostinger para publicar a branch `main` na pasta pública do domínio.
